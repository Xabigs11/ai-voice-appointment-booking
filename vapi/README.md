# Vapi configuration

## Included

- `assistant.public.json`: sanitized export of version `v8` of the Spanish voice assistant. It includes the system prompt, language model, transcriber, voice settings, first message, and analysis settings.
- `check-calendar-availability-tool.public.json`: sanitized `consultar_disponibilidad` tool definition. It accepts `date` and `timePreference` and points to the read-only availability workflow.
- `book-appointment-tool.public.json`: sanitized `reservar_cita` tool definition. It accepts the confirmed lead and appointment details and points to the booking workflow.

The public copy intentionally replaces the two private Vapi tool IDs and the ElevenLabs voice ID with placeholders:

- `YOUR_CHECK_AVAILABILITY_TOOL_ID`
- `YOUR_BOOK_APPOINTMENT_TOOL_ID`
- `YOUR_ELEVENLABS_VOICE_ID`

The source export had the Soniox transcriber restricted to English even though the complete conversation flow is in Spanish. The public configuration corrects `language` and `languages` to `es`. The voicemail and end-call messages were also translated into Spanish for consistency.

Both tool exports preserve their function names, descriptions, JSON schemas, user-facing status messages, timeout settings, and version metadata. Their private n8n production webhook URLs have been replaced with:

- `YOUR_N8N_CHECK_AVAILABILITY_WEBHOOK_URL`
- `YOUR_N8N_BOOK_APPOINTMENT_WEBHOOK_URL`

## Recreate the configuration

Create the two tools from the public definitions, replace each webhook placeholder with the corresponding n8n production URL, and then replace the named tool-ID placeholders in `assistant.public.json` with the IDs generated by Vapi.

Do not commit private API keys, credential IDs, private n8n webhook URLs, phone-number IDs, organization IDs, private voice IDs, or unredacted call data.
